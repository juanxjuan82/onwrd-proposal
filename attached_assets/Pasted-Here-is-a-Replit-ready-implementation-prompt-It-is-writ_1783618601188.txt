```markdown id="48391"
# ONWRD Proposal Desk — Automated Tender Intelligence Engine

## Feature: Daily Tender Source Crawling + AI Opportunity Discovery

## Objective

Build an automated tender discovery system that runs daily, discovers relevant procurement opportunities for ONWRD, filters irrelevant tenders, scores opportunities, and automatically feeds qualified opportunities into the existing AI proposal pipeline.

The system should support:

- Bahamas government tenders
- Caribbean development opportunities
- UN procurement
- IDB and multilateral development opportunities
- NGO opportunities
- Development-sector consulting opportunities

The goal:

> Automatically find, analyze, and prioritize the opportunities ONWRD should pursue without manually searching tender portals.

---
```

# Cron Automation

Create daily scheduled job.

Run:

```
Every day at 6:00 AM
```

Process:

```
1. Run all active source adapters

2. Collect opportunities

3. Normalize data

4. Check duplicates

5. Save new tenders

6. Download documents if available

7. Run AI classification

8. Score ONWRD fit

9. Notify team
```

---

# Duplicate Detection

Prevent duplicate opportunities.

Match using:

* source URL
* tender ID
* organization
* title similarity

Example:

Existing:

```
UNDP Climate Communication RFP
```

New crawl:

```
UNDP Climate Communications Consultancy
```

AI should recognize as same opportunity.

# Success Criteria

The feature is successful when:

1. ONWRD no longer manually searches multiple tender portals
2. Relevant opportunities arrive daily in a prioritized inbox
3. Team spends time only reviewing high-value bids
4. Every accepted opportunity flows automatically into proposal generation
5. Source performance data improves future opportunity selection

```

A note for implementation: I would ask Replit to build this in **two phases**.

**Phase 1 (fastest ROI):**
- `tender_sources` table
- daily cron
- UNGM + IDB + Bahamas sources
- AI filtering
- discovered opportunities inbox

**Phase 2:**
- more crawlers
- source performance analytics
- automatic learning from wins/losses
- procurement portal integrations

The crawler layer should be built as the foundation because it becomes the top of your entire ONWRD bid engine.
```
